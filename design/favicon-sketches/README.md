# Strongroom favicon sketches

Three options only. **Nothing is wired into the app yet** (no changes to public/*.html or server.js).

Colours (from the Fin & Co server icon): rust `#a8261c`, cream `#ece6d6`. Nothing else. Drawn on a 32-unit grid, bold shapes only.

- `vault-door.svg` - cream round door on a rust rounded square, chunky rust cross handle and hub.
- `keyhole.svg` - cream keyhole on a rust rounded square (Glenn's idea).
- `padlock.svg` - cream padlock with thick shackle on a rust rounded square, rust keyhole in the body.

Each has `-16.png`, `-32.png`, `-64.png`. `contact-sheet.png` compares all three at actual size and enlarged, on light and dark backgrounds.

Rendered with headless Chrome (transparent background outside the rounded square).
